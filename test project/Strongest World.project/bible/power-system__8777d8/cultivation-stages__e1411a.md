Ranks per level: low, mid, high, peak, half-step.

**Humans** — [Mortal] Qi Gathering → Spirit Building → Bloodline Awakening; [Earth] Foundation Establishment → Core Condensation → True Lake; [Heaven] Revolving Core → … → True God.

**Demons** — Flood Demon → Awakening → Manifestation → Ascension.

The two ladders converge at **Worldly King** (undying body) → **Spirit King** (undying spirit) → Harmony/Unification → Distraction → **Creator** (the strongest state — able to destroy whole folds). A Flood Demon is roughly a peak Bloodline-awakened human.
